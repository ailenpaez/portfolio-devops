# Portfolio DevOps — Ailén Páez

Landing personal para mostrar mi camino de QA Manual / Backend hacia DevOps.

🔗 **Demo:** x

## Sobre el sitio

- Diseño oscuro, responsive, sin frameworks — HTML + CSS puro
- Terminal animada en el hero
- Skills actuales (backend, QA, herramientas) con logos reales vía [Devicon](https://devicon.dev/) y [Bootstrap Icons](https://icons.getbootstrap.com/)
- Roadmap de aprendizaje: Linux, Docker, CI/CD, Kubernetes, Terraform
- Sección de proyectos (placeholders, en construcción)

## Stack

- HTML5 / CSS3
- Sin build tools ni dependencias — solo abrir `index.html`

## Correr localmente

```bash
git clone https://github.com/ailenpaez/portfolio-devops.git
cd portfolio-devops
```

Abrí `index.html` en el navegador, o serví la carpeta con cualquier servidor estático:

```bash
python3 -m http.server 8000
```

## Deploy

Publicado con **GitHub Pages** desde la rama `main`, carpeta raíz (`/`).
